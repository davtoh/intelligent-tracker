> **Locked Design Decisions (Zero New Overlapping UI Components)**:
> 1. **Reversible `review_decisions` Audit Trail (`ADR-19`, `BUG-24`)**: Upgrade SQLite to `PRAGMA user_version = 5` with a dedicated `review_decisions` table and `ReviewDecisionMixin` (`intelligent_tracker/repositories/review_decision_repo.py`). > 3. **Studio Minimap Zoom/Fit/Pan, 4-Point BEV Quad & `< 260L` Split (`BUG-25`)**: Add zoom/fit/pan + `World Map` <-> `Selected Camera BEV` toggle to `WorldTacticalMinimap` (preserving 6-arg `toCanvasXY`/`toWorldXY` compatibility), draw saved 4-point BEV calibration quads (`homography.src_points`, toggleable `All / Selected / Off`) and optional live/video `UnifiedCanvasOverlay` track overlays on `#studio`, and split `dashboard/static/js/studio_canvas.js` (`325L` -> `< 260L` via `studio_media.js` in `partials/scripts_studio.html`) to restore `tests/test_step4_studio_shape_editor_ui.py` budget compliance while keeping `studio.js <= 349L`.
> 4. **Journey, Analytics & Shared Snapshot Modal Isolation (`ADRs 09, 12`)**: Enable empty-prefix (`q=""`) focus/click entity suggestions in `#journey` (`journey_search.js`), add `zone_id` / `event_type` filters + bucket page controls + `video:<filename>` sighting parity to `#analytics` flows, extract `snapshot_modal_overlay.js` from `alerts_view.js` (`349L` -> `< 270L`) to hydrate alert zones/tripwires with a `ResizeObserver`, fix `"All Cameras"` filter selection in `#alerts`, and reset `#snapshot-modal-canvas` / `#snapshot-modal-controls` when `#timeline` opens `#modal-snapshot-view`.
