# Frontend, Multiview & Node VM Test Invariants

## 1. Component Reuse, Single-Control & Zero-CLS HUD Contract
- **Component Reuse & Ask-Before-Creating-New-Component Rule**: Before creating any new UI component, toolbar, modal, or canvas renderer, inspect existing modules in `dashboard/static/js/` and `dashboard/static/partials/`. Reuse and parameterize existing components via presentation variants (e.g., `OverlayControlBar` with `variant: 'live'` / `'scrubber'`, `UnifiedCanvasOverlay`), keep one canonical control per action per view (zero duplicate/dead buttons), and **explicitly ask the user before creating a new UI component that overlaps an existing one**.
- **Zero-CLS Dynamic HUD Contract**: Dynamic telemetry bars/badges (`AI Lag`, scheduler tiers, camera titles) must define explicit `>= 8px` gaps, `tabular-nums`, reserved slots with smoothing/hysteresis (no frame-by-frame `hidden` flicker), and `min-width: 0; overflow: hidden; text-overflow: ellipsis` truncation containment.
- **HiDPI `<canvas>` Hit-Testing & Pointer Events**:
  - When scaling an overlay `<canvas>` via `UnifiedCanvasOverlay.syncCanvasDpr(dpr)`, hover hit-testing and tooltip placement MUST divide by CSS layout dimensions (`canvas.style.width` / `canvas.style.height` or `getBoundingClientRect()`), never backing-store pixel dimensions (`canvas.width` / `canvas.height`).
  - When attaching pointer/ROI handlers to an overlay `<canvas>` (`#interactive-canvas`, `#scrubber-overlay-canvas`), verify its CSS sets `pointer-events: auto` (not `none`).
  - In `#scrubber-overlay-layers`, use `.overlay-feature-pill` for feature visibility toggles (`BBoxes`, `IDs`, `Dwell`, `Velocity`, `Zones`, `Tripwires`) and reserve `.overlay-layer-chip` exclusively for analysis run layer chips.

## 2. Multiview Socket Budget & Viewing != Analytics
- **Socket Budget**: Each SPA tab uses at most `1` `/ws/multiview` socket + `1` 1x1 MJPEG `/stream/{id}` (or `<= 4` MJPEG sockets on `2x2` pages during 3-failure degraded fallback), sending `unsubscribe_all` when leaving the grid and closing after 30 s idle or on `pagehide`. Always call `LivePlayer.detachGridStreams()` before `innerHTML` grid teardown.
- **Viewing != Analytics**: Grid `/ws/multiview` subscriptions wake capture via `annotated=False` subscriber leases and share encoded `ThumbnailCache` tiers per camera/width, without altering `ProcessingModeService.should_run_vision_step()` (`armed` cameras stay awake except under `paused`); `MultiviewSession` must drain status JSON and binary JPEG frames before throttled telemetry JSON so binary frame consumers receive the frame right after `source_status`.
- **Clean vs. Annotated Stream Contract (`?annotated=false|true`)**: Preserve `annotated: bool = True` as the default on `GET /stream/{camera_id}` and `StreamManager.get_latest_frame_jpeg()`; pass `?annotated=false` explicitly on `#live`'s primary interactive viewport so freeze-frame ROI crops remain free of burned-in pixels.
- **Zero Hardcoded `'cam_01'` Defaults**: Never default `ProcessingModeService.focused_camera_id` or frontend stream/WebSocket/studio/AI-config fallbacks to `'cam_01'`. `ProcessingModeUI.isValidCameraId()` must return `false` while `availableCameras` is `null` (before `/api/cameras` loads), and stream/WS/studio attach helpers must guard on a resolved non-empty camera ID.
- **Cross-Video View Isolation & Auto-Switch**: In `video_batch.js` and `video_library.js`, all async job listeners (`job-started`, `job-update`, `job-finished`) must verify `currentBatchFilename === job.filename` before updating DOM containers, and auto-switch `videoPlayer.src` when `_h264.mp4` conversion finishes for `currentViewedFilename`.

## 3. Enforced HTML/JS/CSS Line Budgets & Node VM Test Rules
- **Strict File Line Caps** (enforced by `tests/test_step3_architecture_budgets.py`, `tests/test_step3_tag_modal_integration.py`, and legacy budget tests):
  - `dashboard/static/index.html < 180` lines
  - `dashboard/static/partials/tabs/live.html < 220` lines
  - `dashboard/static/js/processing_mode.js < 220` lines (reading `data.camera_states` with `data.cameras` fallback)
  - `dashboard/static/css/processing_mode.css < 140` lines
  - `dashboard/static/js/scheduler_hud.js < 180` lines
  - `dashboard/static/interactive_canvas.js < 240` lines (centralize scale-factor resolution in `getActiveScales()` and keep `live-stream-img || video-stream` fallback)
  - `dashboard/static/camera_ai_config.js < 280` lines
  - `dashboard/static/js/studio.js <= 350` lines
  - `dashboard/static/camera_manager.js <= 366` lines
- **WebIDL Timer Wrapping**: Wrap native timer methods (`window.setTimeout`, `window.clearTimeout`) in arrow functions (`(fn, ms) => setTimeout(fn, ms)`) rather than storing bare function references on class instances (`TypeError: Illegal invocation` in V8).
- **Fetch Clone & HTML Asset Regex**: Shared `fetch` deduplication helpers MUST return `resp.clone()` before callers invoke `.json()` or `.text()`. Match real HTML asset tags with negative lookbehind `(?<!data-)src=` in static tests so lazy-loaded `data-src=` attributes do not trigger false failures.
- **Node VM (`vm.runInNewContext`) Test Discipline**:
  - Keep every test method strictly `<= 40` lines (`diagnose.py audit`).
  - Execute async test bodies inside `vm.runInContext(ctx)` rather than the outer Node realm so reassigned globals (`fetch`, `Image`) bind to the VM context.
  - When testing `studio.js` incremental/delta list rendering, stub DOM creation/diff hooks (`document.createElement` with `children: []` and `appendChild`, row stubs, `StudioOverlays.renderScenarioListUI`/`renderTopologyLinksUI`) in small (`<= 40L`) helpers, and measure BEV minimap timer activity via delta renders across `_tickIntervals()`.
  - When testing async `fetch().then(r => r.json())` flows in Node VM without timers, flush multiple microtask ticks (or await the returned init promise) before asserting DOM updates.
  - When extracting a new JS helper module (e.g., `multiview/grid_tile_overlay.js`, `camera_form_helpers.js`, `app_ui_helpers.js`, `video_jobs_ui.js`) or adding multi-sample HUD hysteresis (`LivePlayer.updateInferenceLagHud` 3-sample lag window), keep a standalone fallback in the parent module or load the extracted file in existing Node VM harnesses (`git grep -n "<parent>.js" tests/`).
  - Keep `analytics.html` free of eager `src="/analytics/heatmap"` so cold-boot `#live` never fetches heatmaps early; attach on `#tab-analytics` entry or active init.
  - When probing MJPEG `<img>` streams in headless Chrome, wait on `naturalWidth > 0` (never `img.complete`), and ensure `#studio-camera-select` `change` is dispatched after channel load.
  - Always grep legacy Node VM contract tests before changing URL query-param formats or eager HTML `src` attributes.
  - Plain JS DOM stubs in Node VM tests do not coerce numeric `input.value` to string like real `HTMLInputElement`; coerce in the stub or assert `String(el.value)`. Pass `json.dumps`-wrapped JS source strings to `vm.runInContext` instead of outer JS template literals when inner scripts contain backticks.

## 4. Modal Ergonomics, `MediaEmptyState`, Tag UX & Interactive Studio (`ADRs 10–12`)
- **Responsive Modal Grid & `MediaEmptyState`**: Keep wide dialogs adaptive (`width: min(94dvw, 1240px)`, `resize: both`, `@container (inline-size < 900px)` collapse, `min-width: 0` on `.modal-left-col`/`.modal-right-col`) with defined `.form-row`/`.col-*` rules (`modal_forms_grid.css`); never render raw empty `img.src = ''` or unguarded `<img>` icons — mount shared `MediaEmptyState` (`media_empty_state.js`) across `#studio-live-img`, `#static-heatmap-img`, `#tag-roi-crop-img`, `#snapshot-modal-img`, `#enroll-crop-preview-img`, and `#test-preview-img`.
- **Unified Enrollment Stage & Two-State `#modal-tag-entity`**: Display explicit source context on `#gallery` Enrollment, scrub `<video>` directly behind `#enroll-bbox-canvas` at real FPS (no stacked duplicate `<video>`), sync on `timeupdate`, and preserve `video_filename`/`media_offset_sec`; split `#modal-tag-entity` into *Known Match* (pre-filled + `"Confirm Match"` + in-place `"Not <Name>"`) vs. *New Subject* (hide `"Not This"`, candidate `✕` suppresses in-place without `closeTagModal()`), invalidate `OverlayLayers.streamCache` on `{ force: true }`, and route drawer/hash modal opens through `openModal()`.
- **Traceability, Alert Lifecycle & Interactive `#studio`**: Populate `#alerts-filter-camera` from `/api/cameras`, drive alert badges from unread counts (not `recent_alerts.length`), add `#timeline` `offset` pagination + Source jump links, `#analytics` X/Y scales + peak/`32x24` hotspot clicks, and `#studio` idle-mode vertex editing + interactive minimap camera cones (filtering deleted/stale poses).

## 5. `SourceRef` Navigation, Canvas Drag Capture & Modal Grid Invariants (`ADRs 15, 18`)
- **`App.navigate(tab, SourceRef)` & `ActiveSourceContext` (`ADR-15`)**: Route all cross-tab jumps through `App.navigate(tab, sourceRef)` (`#live?camera=...`, `#studio?camera=...&zone=...`, `#timeline?source=...&from=...&to=...`), never calling `switchTab()` before setting source; `switchCamera()` must atomically sync `#live-stream-img`, `#active-camera-select`, `#video-stream-title`, and `CameraManager.focusCamera`. Share `ActiveSourceContext` selectors across `#live`, `#analytics`, `#studio`, and Enrollment (with Pause/Resume `/freeze_frame` in Enrollment & Studio).
- **Async Filter Population & Safe Data URIs**: Always `await` filter dropdown population (`loadTimelineFilters`, `loadStudioChannels`) before applying selected filter values. Percent-encode `data:image/svg+xml` data URIs with zero HTML character entities (never `&bull;`).
- **Canvas Pointer Capture & Adaptive Modal Grids**: Bind `setPointerCapture` / window-level `pointerup` (`mouseup`) on drag editors (`StudioCanvas`) so pointer releases outside the canvas never strand `_drag`. Use auto-fit grids (`minmax(min(100%, 440px), 1fr)`) on `.modal-lg` rather than cramped `1fr 1fr`, with `min-width: 0` and `flex-wrap: wrap` on `.section-subhead` and selects. Reuse `#modal-tag-entity` with a track picker strip for overlapping boxes and Quick-Tag queues.
- **Step 4 Surface Strictness & Legacy VM Fallbacks**: Avoid `btn-*` class names in JS `closest()`/`contains()` checks when not backed by a matching HTML `id` so `diagnose.py surface --verify --strict` stays at `0` mismatches. When extracting helpers into new script files (e.g., `studio_media.js` from `studio.js`), keep standalone DOM fallbacks in the parent JS module so legacy Node VM harnesses that only load the parent module remain green.
- **Studio Clean Stream, Chip Isolation & Timeline/Review Contracts (`ADRs 22–23`)**: Attach `#studio-live-img` with `?annotated=false`, export `ScrubberOverlay.getCurrentTracks()`, and redraw `#studio-drawing-canvas` on live telemetry ticks (`OBS-028`, `OBS-029`). Exclude `.btn-cat-chip` and `.btn-gallery-ent-chip` from `CameraAIConfig.getPresetButtons()` (`OBS-036`). Render a visible active-range chip + Clear/Reset button in `#timeline` (`OBS-035`), and display DB `total_pending` (not page `items.length`) in `#header-review-badge` and `#review-inbox-counter` (`OBS-048`).
